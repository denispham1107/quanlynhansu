# Sửa dứt điểm 6 ô trạng thái nhân viên trên desktop

- Di chuyển khối `adminEmployeeStatusSummary` ra khỏi cột tiêu đề để nó chiếm toàn bộ chiều rộng của panel.
- Desktop từ 1000px: 6 cột bằng nhau trên một hàng.
- Tablet 600-999px: 3 cột.
- Mobile dưới 600px: 2 cột, không tràn ngang.
- Không thay đổi ID, dữ liệu, hàm render hoặc logic thống kê.
